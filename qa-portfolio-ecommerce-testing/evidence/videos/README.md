# Vídeos

Usar vídeo somente quando uma imagem não representar bem o comportamento, como intermitência, sequência ou mudança visual rápida.

## Convenção

`<ID>_<AAAA-MM-DD>_<descricao-curta>.mp4`

## Regras

- manter vídeos curtos;
- não gravar senha, token ou informação pessoal;
- remover áudio desnecessário;
- registrar frequência de reprodução;
- preferir link externo controlado caso o arquivo fique muito grande.
