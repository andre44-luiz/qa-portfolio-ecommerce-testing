# Capturas de tela

Salvar somente evidências úteis e sem dados sensíveis.

## Convenção

`<ID>_<resultado>_<descricao-curta>.png`

Exemplos futuros:

- `TC-WEB-001_aprovado_catalogo.png`
- `BUG-001_reproducao-2.png`

## Regras

- ocultar senhas e tokens;
- capturar contexto suficiente;
- evitar imagens redundantes;
- relacionar o arquivo ao caso ou bug;
- não adicionar evidência simulada como se fosse real.
