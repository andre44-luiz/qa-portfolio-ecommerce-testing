# BUG-XXX — Título objetivo

- **Classificação:** Bug confirmado
- **Resumo:** descrição curta do impacto e do comportamento.
- **Ambiente:** sistema operacional, navegador ou cliente, versão, resolução e URL.
- **Versão/data do sistema:** registrar o que estiver disponível.
- **Pré-condições:** estado necessário antes dos passos.
- **Passos para reprodução:**
  1. ...
  2. ...
  3. ...
- **Resultado atual:** comportamento realmente observado.
- **Resultado esperado:** comportamento verificável com base no requisito, documentação ou consistência confirmada.
- **Severidade:** Crítica / Alta / Média / Baixa.
- **Justificativa da severidade:** impacto técnico e no usuário.
- **Prioridade sugerida:** Alta / Média / Baixa.
- **Justificativa da prioridade:** urgência e valor de correção.
- **Frequência:** X de Y tentativas.
- **Evidências:** imagem, vídeo curto, request/response, console ou log.
- **Caso relacionado:** TC-...
- **Requisito relacionado:** REQ-...
- **Informações adicionais:** dados, hipótese, comparação e limitações.
- **Status:** Novo / Em investigação / Confirmado / Em correção / Pronto para reteste / Fechado / Reaberto.

## Checklist antes de confirmar

- [ ] Reproduzido pelo menos duas vezes ou justificada a intermitência.
- [ ] Dados e pré-condições revisados.
- [ ] Resultado esperado possui base verificável.
- [ ] Evidência não contém senha, token ou dado pessoal.
- [ ] Não é indisponibilidade externa.
- [ ] Não é apenas preferência de interface.
- [ ] Não duplica outra issue.
